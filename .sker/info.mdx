Sonixy is a desktop application designed for creators who need a fast, reliable way to manage their audio collections.

## Features

- **Blazing Fast**: Engineered for performance, handling large audio libraries with ease.
- **Modern UI**: A clean, intuitive interface built with Svelte 5.
- **Precision Auditioning**: Tools designed for creators to quickly listen to and manage audio files.
- **Cross-Platform**: Leverages Tauri for a lightweight native experience.
- **Precision Tools**: Includes normalization and trimming features (requires FFmpeg).

## Tech Stack

- **Frontend**: Svelte 5, Vite, TypeScript
- **Backend**: Rust, Tauri
- **Dependencies**: FFmpeg for advanced audio processing
